## ✨ Features

* 🚀 **Instant Section Switcher:** Effortlessly switch between CSIT Sections (A, B, C, D, E, F, G).
* 📅 **Comprehensive Details:** View lecture timings, subject codes, faculty initials, lab rooms, and remedial classes in one view.
* 📱 **User-Friendly Layout:** High contrast, clear navigation, and easy-to-read table structure.
* ⏱️ **Real-time Accessibility:** No need to search through crowded WhatsApp groups or download static PDFs.
